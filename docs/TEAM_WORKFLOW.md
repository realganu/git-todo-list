# Four-Member Collaboration Plan

## Member 1 – Repository Manager
Task:
- Create GitHub repository
- Initialize local repository
- Create README
- Add initial project files
- Push `main`

Branch:
`feature/repository-setup`

Suggested commits:
- `Initial project setup`
- `Add project documentation`

## Member 2 – UI Developer
Task:
- Create HTML structure
- Design CSS
- Build task input and buttons

Branch:
`feature/todo-ui`

Suggested commit:
`Add To-Do List user interface`

## Member 3 – JavaScript Developer
Task:
- Add task
- Complete task
- Delete task
- Clear completed tasks
- Task counter

Branch:
`feature/todo-functionality`

Suggested commit:
`Add To-Do List functionality`

## Member 4 – Tester & Documentation
Task:
- Test all features
- Record bugs
- Prepare screenshots
- Update Git documentation
- Prepare presentation

Branch:
`feature/testing-docs`

Suggested commit:
`Add testing and Git documentation`

## Collaboration Sequence
1. Member 1 creates repository.
2. Members clone the repository.
3. Each member creates their own feature branch.
4. Members make changes and commit them.
5. Members push their branches to GitHub.
6. Pull Requests are created.
7. Team reviews changes.
8. Pull Requests are merged into `main`.
9. Final application is tested.
10. Presentation is delivered.
