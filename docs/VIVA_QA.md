# Viva Questions and Short Answers

### 1. What is Git?
Git is a distributed version control system used to track changes in source code.

### 2. What is GitHub?
GitHub is a cloud platform for hosting Git repositories and collaborating with other developers.

### 3. What is a repository?
A repository is a project location containing files and the history of changes tracked by Git.

### 4. What is staging?
Staging selects changes that will be included in the next commit.

### 5. What is a commit?
A commit is a saved snapshot of staged changes with a message.

### 6. Why do we use branches?
Branches allow developers to work on separate features without directly modifying the main branch.

### 7. What is a remote?
A remote is a reference to another repository, commonly a GitHub repository.

### 8. What does git push do?
It sends local commits to the remote repository.

### 9. What does git pull do?
It downloads and integrates changes from the remote repository.

### 10. Why use Pull Requests?
Pull Requests allow team members to review changes before merging them into the main branch.

### 11. What is merge?
Merge combines changes from one branch into another branch.

### 12. What is the purpose of .gitignore?
It tells Git which files or folders should not be tracked.
